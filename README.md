# Jobora — premium job portal demo

Jobora is a frontend-only, responsive recruitment discovery experience built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Features

- 16 local demonstration listings with search, location/category/type/experience/salary filters, and sorting.
- Responsive job cards, job details, bookmarks, and a validated application-preview flow.
- Company directory, career advice articles, mobile navigation, and reduced-motion support.
- No backend, database, authentication, API integration, or application submission. Listings are illustrative and are not verified live vacancies. Application data is not transmitted or stored.

## Deployment

The project is a standard Vite static site and can be deployed to Vercel with the Vite framework preset, `npm run build`, and `dist` as the output directory.
